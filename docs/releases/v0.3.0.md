# v0.3.0

First DeepAI Connect open-source preview, released under the MIT license. The Linux arm64/amd64 CLI manages Headscale/DERP and FRPS/Caddy, registers native Tailscale peers, and exports standard FRPC configurations or profile v1 JSON for custom clients.

## Existing installations

Connect uses a new executable, module, state directory (`deepai/connect`), state file (`connect.json`) and Docker resource namespace. Version 0.3.0 targets fresh Connect deployments. Earlier previews require an explicit migration; automatic migration is not provided. Keep the previous executable, private state and Docker volumes until that migration is planned. Renaming a state file or passing its old directory to Connect is not a migration.

An existing **Connect** deployment resumes with `deepai-connect up` under its original account and `--dir`. Application domains, addresses and credentials require planned maintenance to change.

## Preview scope

Builds require Go 1.26.9 or newer and produce the two Linux binaries plus checksums directly in `dist/`. See [build and test instructions](../../README.md). Public DNS/ACME, physical-network behavior, reboot recovery and offsite restore require field acceptance. Artifacts are unsigned; application deployment, automatic restore, credential rotation and redundant servers are outside this preview.

Validated on 2026-10-11 with Go 1.26.9: race tests, vet, isolated offline source tests/build, both Linux builds and checksums, and Linux arm64 CLI smoke tests. Disposable Docker tests passed peer registration, forced DERP, standard FRPC publication, invalid-credential and unconfigured-host rejection, and HTTP/2 streaming across a 65-second pause. Govulncheck v1.8.0 found no known vulnerabilities in Linux arm64 source or either binary; container images were outside those scans.
